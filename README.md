2.2.0 真实执行修复

删除不兼容部分MoviePilot V2前端的自定义启动按钮。

STRM分页增加“立即运行一次STRM整理”开关。

原网盘分页增加“立即运行一次原网盘整理”开关。

开启对应开关并点击配置页底部“保存”后，由后端 init_plugin() 直接启动任务。

任务启动后一次性开关自动复位，不会在容器重启时重复运行。

即使前端不支持API按钮事件，也能可靠执行。

2.1.0 界面修复

配置页新增“STRM 文件整理”和“原网盘整理（CD2）”两个分页。

CD2分页首行显示 WebDAV 地址，随后填写用户名、密码和原网盘路径。

修正 MoviePilot v2 的按钮事件格式，点击后能够真正调用后台任务。

插件“数据”页显示任务状态、扫描/识别/移动/复制/跳过/失败统计及最近300条日志。

日志最多保留500条，并写入插件数据，MoviePilot重启后仍可查看。

本插件用于 115 + CloudDrive2 + MoviePilot + Emby 流程，提供两种互斥的低占用整理方式。

模式一：STRM 文件整理

只读取 .strm 的文件名、路径和最多 4 KiB 文本，不读取视频。

以影片或剧集顶层文件夹为整理单元，避免逐集反复移动。

命中分类后移动 STRM 标题文件夹；同文件系统优先使用原子重命名。

适合只调整 Emby 所用 STRM 目录结构，不改动 115 原始文件的情况。

模式二：CloudDrive2 网盘直整（推荐）

通过 CD2 内置 WebDAV 获取 115 目录信息。

使用服务端 MOVE / COPY，视频数据不经过 MoviePilot 容器和 NAS 内存。

Remux 服务端复制；平台与伦理专区服务端移动。

地址示例：http://192.168.1.2:19798/dav。

建议在 CD2 中创建一个仅允许访问媒体目录的可写 WebDAV 用户。

自动识别目录

电影和电视剧目录留空时，会依次尝试：

/115/电影
/115/电视剧
/电影
/电视剧
/媒体库/电影
/媒体库/剧集

若未识别到，可直接填写 CD2 WebDAV 中显示的完整路径，如 /115/电影。

插件在每个媒体根目录内创建分类：

/115/电影/

├── 奈飞专区/
├── 迪士尼专区/

/115/电视剧/

分类优先级

成人/伦理关键词优先归入 伦理专区。

电影名称或浅层文件名包含 Remux，归入 电影Remux归档。

再依次识别 Netflix、Disney、HBO/其他平台、Apple TV。

无法确定的平台保持原位并计入跳过，不猜测、不乱移。

资源与安全优化

默认开启演练模式，只输出计划，不真实整理。

后台执行并带单任务锁，防止连续点击重复处理。

CD2 只先列一次媒体根目录，未命中时才浅层探测，默认深度 2。

每个标题最多读取 12 个 STRM，每个只读 4 KiB。

单次任务默认最多 500，避免一次误操作波及整个网盘。

按整部影片/整部剧集目录操作，减少 CD2/FUSE 元数据请求。

不创建源根目录；路径或挂载异常时直接停止。

重名自动追加 _1、_2，不覆盖现有内容。

使用顺序

将新版代码上传到 plugins.v2/mediaarchiver/__init__.py。

把 package.v2.json 放在仓库根目录。

在 MoviePilot 刷新插件市场并升级到 2.2.0。

选择模式并填写目录或 CD2 WebDAV 信息。

保持“演练模式”开启，在目标分页打开“立即运行一次”，然后点击底部保存。

确认识别结果后关闭演练模式，再正式执行。

完成后刷新 Emby；Sa 若会操作同一目录，请与本插件错峰运行。

后端接口：

POST /api/v1/plugin/MediaArchiver/run

GET /api/v1/plugin/MediaArchiver/status
