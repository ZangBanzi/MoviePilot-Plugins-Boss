## 本次完成

- 原生旧封面备份单独使用 64 MiB 上限；流式累计限制，校验真实格式及首帧后保存原始字节，GIF 全部帧、时长与循环信息不变。失败在上传前停止，报告明确标出备份阶段。
- 本库海报限额提升至 16 MiB，校验后缩至最长边 960 像素并以 JPEG 缓存，避免把大原图堆在内存。原生/虚拟管理端和当前用户播放端一致处理，原图备份不走此转换。元数据有独立 16 MiB 上限。
- encode 的可选 report 参数返回 render_info，兼容旧的二元返回值。预览、历史、任务结果保存真实输出格式、去重后素材数及静态原因。空库、单图、重复图、坏图、品牌模式、编码失败分别记录。
- 任务按 GIF、静态、失败计数，失败也有逐库结果。界面在画布、服务器卡片、历史和运行状态显示原因；JPEG/WebP 不再误标成 PNG，旧记录不臆测原因。
- 0 部空库仍生成静态品牌图；有成员但取图失败与无成员分别提示。未放宽伦理/榜单识别，未使用别库素材或假动画。

## 保留的工作流

主选择框以 Emby 服务器为单位，各库独立取材。“预览整台服务器”只读；“生成并应用整台服务器”逐库备份后更新原生 Primary，并生成当前网关虚拟库历史。第二服务器不改变播放网关。

原生目标按服务器及 ID 精确定位，发布前重新校验。虚拟封面由当前用户权限取材；无登录头图片仍使用绑定用户和库的短期 ImageTag，逐次重新鉴权，不公开管理员历史图片。

客户端 → NextEmby 8098 → MoviePilot API 3334 → Emby 8096，MP 前端 3333。无新插件端口，无媒体文件操作，无 ItemId、MediaSource 或 Location 改写，无 Collection/BoxSet。Cron/增量不发布原生图片。

历史总量仍限 256 MiB，大批次可能淘汰较早备份，不能承诺无限保留原图。需长期留存的原图可下载。
